# Vizi by Vizora

Pequeña demo web para un asistente virtual de restaurante que responde como Vizi, un anfitrión culinario digital.

## Funcionalidades

- Menú con platos destacados
- Búsqueda de información por nombre de plato
- Respuestas sobre calorías, peso, temperatura, ingredientes y alérgenos
- Sugerencias de vino, cócteles y postres
- Comportamiento autónomo: no deriva al personal ni pide confirmaciones innecesarias
- Simulación de escaneo QR

## Ejecutar

Desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Luego abre:

```text
http://localhost:8000
```
